# WorqAI Marketing Intelligence

This repository is a Claude-first marketing intelligence workspace for WorqAI. The user interacts through ordinary prompts, never through terminal instructions.

## Automatic Activation

Treat any request about WorqAI marketing, reels, carousels, posts, motion videos, replies, pitches, universities, institutions, SEO, research, audits, campaigns, or content performance as a WMI task. Load `.claude/skills/worqai-marketing-intelligence/SKILL.md` and follow its complete compile, create, validate, and repair loop.

Support English and Spanish/LatAm. Preserve pasted source material and its original subject. A request that combines research with creation must perform both.

## Operating Contract

- Python compiles compact context, routing, brand memory, research evidence, validation, workspace capabilities, and performance learning.
- Claude performs the novel strategic and creative judgment.
- Return the useful marketing work directly. Do not ask the user to run commands.
- Never present built-in fallback patterns as live research.
- Never invent testimonials, performance data, product behavior, experience, or credentials.
- Qualify ATS claims and never guarantee interviews, jobs, rankings, or filter passage.
- Do not write into another WorqAI workspace until the user approves the named target and intended changes.

## System Map

- `src/worqai_marketing_intel/`: intelligence engines and orchestration.
- `brand/`: editable voice, positioning, and taste sources.
- `config/`: agents, routing, workspaces, and production capabilities.
- `.claude/skills/worqai-marketing-intelligence/`: Claude activation and workflow.
- `production/`: generated briefs, research, and approved handoff artifacts.
- `tests/`: behavioral and safety contracts.

The full architecture and examples are documented in `README.md`.
