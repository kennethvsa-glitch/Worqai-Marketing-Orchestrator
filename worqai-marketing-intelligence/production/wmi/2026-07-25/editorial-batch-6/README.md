# WorqAI — six additional editorial carousels

This batch is independent from the earlier Antigravity outputs.

Each carousel contains:

- one editable HTML production file;
- seven rendered 1080 × 1350 PNG slides;
- one Instagram caption with hashtags;
- one contact sheet for visual review.

## Campaigns

1. `01-career-change` — changing careers without erasing prior experience
2. `02-editing` — why strategic deletion makes a CV stronger
3. `03-career-gap` — explaining a career gap honestly
4. `04-junior-evidence` — turning projects into credible junior evidence
5. `05-senior-criterion` — editing a long career with senior judgment
6. `06-vacancy-strategy` — reading a vacancy as a problem map

All six use Spanish `tú` voice and end with the same offer:

> Comenta CV y te enviamos por DM un código para disfrutar 1 mes gratis de WorqAI Pro.
