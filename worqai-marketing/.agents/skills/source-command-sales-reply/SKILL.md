# source-command-sales-reply

Use this skill when the user asks to run the migrated source command `sales-reply`.

## Command Template

1. Route to growth-agent
2. Load `sales-mastery-expert` + `human-voice-writer` + relevant brand context
3. Identify prospect's stage: discovery, consideration, objection, close
4. Select framework (SPIN for discovery, Challenger for pushing back, Sandler for qualification)
5. Match channel tone: WhatsApp short/warm, email structured, LinkedIn professional
6. Include suggested 24h follow-up if no response
