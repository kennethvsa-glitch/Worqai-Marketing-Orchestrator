# WorqAI Brand Assets

This folder holds the visual identity for WorqAI. Agents (especially ads-agent and content-agent) reference these files when building carousels, landing pages, and marketing materials.

## Files

- `colors.md` — Color palette and usage rules
- `typography.md` — Font stack and type scale
- `logo/` — Logo files (SVG, PNG at multiple sizes) — **populate when ready**
- `mockups/` — Product screenshots for marketing use — **populate when ready**

## Priority

Before scaling marketing, finalize:
1. Primary brand colors
2. Typography stack
3. Logo (SVG + PNG 1024px + favicon)

Until these are locked, agents will default to the "Aurora" or "Noir" design system from `.claude/skills/design-systems/SKILL.md`.
