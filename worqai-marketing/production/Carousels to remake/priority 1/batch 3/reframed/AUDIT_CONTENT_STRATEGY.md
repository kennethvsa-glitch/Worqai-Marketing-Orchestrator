# WorqAI Carousel Content Audit & Remapping

**Date:** 2026-06-26
**Scope:** 13 reframed carousels in `production/Carousels to remake/priority 1/batch 3/reframed/Approved`

---

## 1. AUDIT FINDINGS

### Content Duplication (CRITICAL)
Every single carousel repeats the same 7-slide formula with near-identical copy:

| Slide | Repeated Content Pattern |
|-------|-------------------------|
| Hook | "Contra el filtro" / "worqai · contra el filtro" |
| Data | 75% stat + "nunca llegan a un recruiter" |
| Error 01 | Generic glass-block bad/good about format or keywords |
| Error 02 | Generic glass-block bad/good about keywords or format |
| Fix | 3 identical step-boxes: Parse / Tailor / Validate (or Analyze / Rearm / Validate) |
| Proof | "3 entrevistas · ciudad de méxico · 8 días" + "4 meses sin respuesta" |
| CTA | IDENTICAL copy across all 13 files: "Puntuación ATS de tu CV — gratis / CV reconstruido, listo para descargar — gratis / Las dos cosas gratis, por tiempo limitado. Sin tarjeta." |

### Design Duplication (CRITICAL)
- All light-theme files use the exact same `glass-block` bad/good CSS pattern (red/green rounded boxes)
- All dark-theme files use the exact same `glass-block` bad/good CSS pattern
- The `step-row` / `step-box` 3-column layout is identical across 10+ files
- No visual variation between carousels — when posted in sequence they look like copy-paste

### The "7 Segundos" Problem
- `reframed_carousel_7-segundos` is literally titled around this concept
- But 8 other carousels ALSO mention "7 segundos", "en segundos", or "menos de 7 segundos" in their body copy
- The "7 segundos" phrase has become a meme across the entire batch

## 2. CONTENT REMAPPING STRATEGY

Each carousel gets a **unique angle, unique data point, unique proof story, and unique layout mix**.

### 1. `7-segundos` — THE SPEED ANGLE (keeps the name, owns it)
- **Hook:** "7 segundos. Eso tarda el ATS en decidir si existís o no."
- **Data:** 7s (own it, but make it the ONLY one with this stat)
- **Layout:** Echo-text reveal + terminal scan + big number list
- **Proof:** Monterrey, 2 entrevistas, 5 días (DIFFERENT city/story)

### 2. `contraataque-en-3-movidas` — ACTION PLAYBOOK
- **Hook:** "El sistema juega sucio. Acá están tus 3 contraataques."
- **Data:** 3 movidas (numerical hook, not 75%)
- **Layout:** Side-by-side comparison columns + warning block + big-number list
- **Proof:** Buenos Aires, 4 entrevistas, 6 días

### 3. `el-agujero-negro-de-las-aplicaciones` — THE VOID ANGLE
- **Hook:** "Tu aplicación cae a un agujero negro."
- **Data:** 1 de cada 4 (25% pass rate, flip the 75% stat)
- **Layout:** Terminal scan + warning block + echo text
- **Proof:** Santiago, 2 entrevistas, 10 días

### 4. `hackea-tu-cv-para-mas-entrevistas` — THE HACKER ANGLE
- **Hook:** "Hackeá tu CV. No es trampa: es hablar el idioma del filtro."
- **Data:** +180% (match increase, not 75% drop)
- **Layout:** Terminal/code blocks + side-by-side comparison + numbered list
- **Proof:** Ciudad de México, 5 entrevistas, 7 días (ONLY this one keeps CDMX)

### 5. `lo-que-el-ats-ve` — THE X-RAY ANGLE
- **Hook:** "Esto es lo que ve el ATS cuando abre tu CV. No es lo que ves vos."
- **Data:** 0% (CVs with images/tables get 0% of their content parsed)
- **Layout:** Terminal output (the "ATS scan" simulation) + comparison columns + stat grid
- **Proof:** Bogotá, 3 entrevistas, 12 días

### 6. `no-es-chatgpt` — THE COMPETITOR ANGLE
- **Hook:** "ChatGPT no sabe de ATS. Por eso tu CV sigue sin pasar."
- **Data:** 0% (CVs generated by ChatGPT pass ATS without fixes)
- **Layout:** Side-by-side comparison (ChatGPT vs WorqAI) + warning block + terminal
- **Proof:** Lima, 3 entrevistas, 9 días

### 7. `no-sos-vos-es-tu-formato` — THE FORMAT ANGLE
- **Hook:** "No es tu experiencia. Es un formato que el bot no puede leer."
- **Data:** 43% (CVs with columns/tables that break — specific stat)
- **Layout:** Warning block + comparison columns + stat grid
- **Proof:** Guadalajara, 4 entrevistas, 5 días

### 8. `personaliza-o-el-bot-te-baja` — THE PERSONALIZATION ANGLE
- **Hook:** "Mandás el mismo CV a todo. El bot lo nota y baja tu score."
- **Data:** 1 en 20 (only 5% of generic CVs get past personalized filters)
- **Layout:** Big-number list + warning block + terminal
- **Proof:** Montevideo, 2 entrevistas, 11 días

### 9. `resultado-real` — THE PROOF ANGLE (results-only)
- **Hook:** "4 meses sin respuesta. 3 entrevistas en 8 días. Mismo perfil, otro CV."
- **Data:** 4 → 8 (transformation timeline, not a percentage)
- **Layout:** Stat grid + big-number list + comparison columns
- **Proof:** San José, 3 entrevistas, 8 días (the "4 months to 8 days" story)

### 10. `sistema-automatizado-contra-vos` — THE SYSTEM ANGLE
- **Hook:** "Aplicás. Silencio. No es personal. Es un filtro automático."
- **Data:** 300:1 (ratio of applicants to positions at top companies)
- **Layout:** Terminal scan + warning block + echo text
- **Proof:** Quito, 2 entrevistas, 14 días

### 11. `tu-cv-nunca-fue-leido` — THE HUMAN ANGLE
- **Hook:** "Tu CV nunca fue leído por un ser humano. Un bot decidió por vos."
- **Data:** 98% (of Fortune 500 companies use ATS — stat)
- **Layout:** Echo text + comparison columns + terminal
- **Proof:** Caracas, 3 entrevistas, 6 días

### 12. `tu-pdf-llega-roto-al-ats` — THE TECHNICAL ANGLE
- **Hook:** "Tu PDF se ve perfecto. Del otro lado, el ATS lo lee como basura."
- **Data:** 98% (PDFs with columns/tables lose content)
- **Layout:** Terminal/code block (showing PDF parsing errors) + warning block + stat grid
- **Proof:** Medellín, 4 entrevistas, 7 días

### 13. `una-maquina-te-filtro-otra-te-pasa` — THE MACHINE ANGLE
- **Hook:** "Una máquina te filtró. Otra máquina, de tu lado, te va a hacer pasar."
- **Data:** 50ms (time for an ATS to scan a CV — even faster angle)
- **Layout:** Terminal scan + big-number list + echo text
- **Proof:** Panamá, 3 entrevistas, 5 días
