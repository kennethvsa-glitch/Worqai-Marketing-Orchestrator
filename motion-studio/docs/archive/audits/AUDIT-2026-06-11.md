# What this workspace actually is

Two pipelines wearing one name. The documented pipeline — JSON spec → `render_motion.py` → `motion_exporter.py` → MP4 — was built, proven, and shipped its template scenes by June 2. Since then the real work moved to a second, undocumented pipeline: hand-authored narrative scenes (`scene-launch-honest.html`, `scene-launch-villain-v3.html`, sharing `templates/motion-lib.js`) driven by `make_film.py`, a 7-stage orchestrator (export → SFX → VO → music+ducking → loudnorm → captions → cutdowns) fed by film manifests in `films/`. The skill file (`SKILL.md:66-89`) states this plainly — "a new narrative video is a copy of scene-launch-honest.html… The Phase 1 spec→render pipeline does not generate these scenes" — but CLAUDE.md and AGENTS.md, the docs every session loads first, still describe the June 1 workspace and tell the reader the recorder spike is the first thing to build. The spike passed ten days ago.

This is a shipping workspace. The drift is debt, not disease.

# What is working — do not touch

- The determinism discipline. The 9 locks in `motion-determinism.md` are respected in the code that exists; `golden_frames.py` turns the determinism guarantee into an actual regression harness; the label system (`MOTION_LABELS`) cleanly couples scene time to SFX/VO/caption/cutdown placement. This is the workspace's core asset.

- The token sync between `.claude/skills/motion-builder/motion-tokens.json` and `motion/tokens/motion-tokens.json` — diff confirms identical, as documented.
